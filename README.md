# Vendor Performance Analysis Dashboard

## Overview

This project focuses on analyzing vendor performance using Python, SQL, and Power BI. The objective is to evaluate vendor efficiency, sales contribution, and business performance through KPI tracking and interactive dashboards.

## Tools & Technologies

* Python (Pandas, NumPy)
* SQL
* Power BI
* Excel

## Project Objectives

* Evaluate vendor performance and contribution
* Identify high-performing and underperforming vendors
* Analyze sales and operational trends
* Track business KPIs and performance metrics
* Generate data-driven business recommendations

## Analysis Performed

* Data Cleaning and Transformation
* Exploratory Data Analysis (EDA)
* Vendor Performance Evaluation
* Sales Trend Analysis
* KPI Monitoring
* Business Performance Reporting

## Key KPIs

* Total Sales
* Vendor Contribution
* Revenue Performance
* Order Volume
* Vendor Efficiency Metrics
* Performance Trends

## Dashboard Features

* Vendor Performance Dashboard
* Sales Trend Analysis
* KPI Monitoring
* Performance Comparison
* Interactive Business Reports

## Business Insights

The project helps organizations identify top-performing vendors, monitor business performance, optimize vendor relationships, and support strategic decision making through data-driven insights.
